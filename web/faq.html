Questions, answered without rounding up.

The short answers, with the caveats that matter. Each one links to the page or document that carries the mechanics.

Does Rigel need the internet?

Search, the static review, duplicate clusters, the diff and the transcripts are local and stay usable offline. Indexing a source, syncing a marketplace, a model turn, the update check and cloud sync use the network. The update check is one signed request at launch and can be switched off in Settings → Updates.

What actually leaves the machine?

Nothing, unless you press a button that says so. Push sends shelf metadata, never a skill body. Publish sends one session’s prompts and the assistant’s own words, never tool calls, command output or your project path. Provider keys, cloud tokens and the refresh token live in the OS keychain; the renderer does not receive them.

The cloud page lists the documents and the exclusion list.

Which agents does it run?

Codex and Claude Code through their own CLIs, Cursor and Cline through ACP, and a native coordinator with path-checked tools. Each harness is probed as its own row and keeps its own key in the keychain.

Muse Code and Gemini CLI are also driven by the core, but those two are verified against scripted implementations because neither CLI is installed on the build machine. The sessions page marks each harness as real or protocol.

Windows only?

Windows-first: MSI and NSIS installers for Windows 10 1809 and newer. The core is a Rust workspace and the phone client is iOS. Other desktop targets are not a supported surface today, so the site does not list them as one.

Is the cloud a subscription?

No. Rigel is a binary you run. The cloud is a Firebase project you own, on your own bill, or nothing at all. It stays off until you configure it, and the desktop app sends no telemetry whether it is on or off.

What is in the catalogue?

The catalogue holds 11,587 skills measured from public sources. Independent censuses put the public universe at roughly 238,000 unique skills, so a larger number would be padding rather than coverage. Every row names its source, and a body is only kept when Rigel fetched it itself.

The shelf page explains the six static rules, the evidence column and the difference between metadata-only and reviewed rows.

Is there telemetry?

The desktop app sends none. It has no account requirement and no anonymous identifier. This marketing site uses Google Analytics; the application does not, and the contact form on the home page uses reCAPTCHA Enterprise only when you submit it.

Can I use it without an API key?

Yes. The window, the index, the static review, the diff and the tools ledger need no provider. A model turn needs a key for the provider you pick. The deterministic scripted model drives the tests with none.

Does the site show ads?

The home page can show one clearly labelled Gravity-sponsored card. It is requested from Rigel's own Firebase endpoint, so the publisher key stays on the server. The card loads only when Gravity has a fill; the impression fires once, when the card is visible. If your browser sends Do Not Track or Global Privacy Control, the page does not request an ad at all. The desktop app offers the same slot as an opt-in and sends no request while it is off.

Gravity is the only ad network here. No other ad script or image runs on this page.
