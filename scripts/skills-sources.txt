# Agent-skill repositories indexed by scripts/refresh-skills.sh.
#
# One `owner/repo`, GitHub URL, or `owner/repo/tree/<ref>/<path>` per line.
# Blank lines and everything after `#` are ignored.
#
# A repository costs two GitHub API calls per run (metadata and one tree call);
# bodies come from raw.githubusercontent.com and do not count. Without a token the
# quota is 60 an hour, so keep the list around two dozen and set RIGEL_GITHUB_TOKEN
# when you want to walk more.
#
# Add a repository by pasting its GitHub URL here. Re-running the script updates
# skills that changed, adds new ones, and leaves removed ones in place (use
# `rigel skills gc` to drop blobs nothing references).
