## Updates

The update check and auto-install are on by default and can be turned off in Settings → Updates.
0.1.7 installers are unsigned; Windows may show a SmartScreen warning. The update manifest is
Ed25519-signed and every artifact has a published SHA-256.

## Data and support

The local database is not encrypted at rest. The privacy note in [privacy.md](privacy.md) explains
what leaves the machine. Support is through GitHub Issues and Discussions, without a service-level
agreement. Security reports go through [SECURITY.md](../SECURITY.md).
