## Gaps, stated plainly

- **The published MSI was not installed on this machine.** The elevation prompt was cancelled, so
  the host still reports Rigel 0.1.6. The 0.1.6 → 0.1.7 update path and the installed app's version
  are therefore unverified.
- **Windows Sandbox acceptance was not run for this cut.** The feature still needs a boot that
  applies it on this host.
- **Windows 10 1809 and SmartScreen were not exercised**; both need a matching image or a
  browser-downloaded file.
- **Repeat builds are not byte-identical.** WiX and makensis stamp build metadata, so the second
  build's hashes differ. The published hashes, not the local ones, are authoritative.
- The installers are **unsigned**: no trusted Authenticode certificate was available.
