# Phase 3 — exit test

Run this before ticking P3.11. It drives the real `rigel` binary against a throwaway git repository,
with no network and no model key: the model is a deterministic script, while the coordinator,
tools, budget service, patch pipeline, session store and resume path are the production ones.

The whole thing is one command:

```bash
RIGEL_BIN=C:/rigel-target/debug/rigel.exe bash scripts/p3-exit-test.sh
```

On a POSIX checkout, `RIGEL_BIN=target/debug/rigel`; omit it and the script builds
`rigel-cli` itself. It prints `PASS — Phase 3 exit test` and exits 0, or prints `FAIL: …`
and exits 1. Nothing outside a `mktemp` directory is touched.

## Provider and the local router

A real (non-scripted) turn defaults to OmniRoute at `http://127.0.0.1:20128/v1` with model
`gpt-5.6-sol-medium`; `--provider openrouter` or `RIGEL_PROVIDER=openrouter` uses the hosted
gateway instead. `RIGEL_OMNIROUTE_URL` overrides the base URL. The key is `rigel/omniroute` in
the OS keychain (`rigel keys set omniroute` reads stdin), or `OMNIROUTE_API_KEY` for CI.

When `/api/health` does not answer, a turn runs `omniroute serve --daemon --no-open` itself and
polls until the port is healthy. Verified 21 Oct 2026 on Windows: the router was killed (health
`000`), a turn then completed in 11 s with `stop: completed`, and health returned `200` from a
new PID. A router that binds the port but never becomes healthy is reported instead of being
launched twice — two instances share state and the second one hangs.

## What it asserts

| # | Step |Expected |
|---|---|---|
| 1 | One scripted turn on a 25¢ session | three `read_file` calls and one `edit_file` journaled, **4 tool calls in 2 steps**, process exits **70** |
| 2 | State immediately after the kill | turn `running`, patch `proposed`, `git status` clean, no checkpoint |
| 3 | New process: `session resume` | exit **2**, `clean: false`, turn closed as `cancelled`, patch reported `pending`, nothing applied |
| 4 | `patch apply` | status `applied`; one `a.saturating_sub(b)` line in the file |
| 5 | `patch apply` again | idempotent: status `applied`, file untouched, `git diff` sha256 unchanged |
| 6 | `session resume --force` | intervention count **1**; the changed tree becomes the new baseline |
| 7 | A second scripted turn | `completed`; billed $0.0002, like every step |
| 8 | `session resume` again | `clean: true`, no closed turns |
| 9 | The bill | cap **25¢**, spend **1500 µ$** (0¢ rounded: 400 + 900 for the killed turn's two steps, 200 for the finished one), tasks **1**, interventions **1** |
| 10 | A fresh 25¢ session spends $0.31 | exit **3**, `budget_exceeded`, **1 step** (the second never ran), session charged 310 000 µ$ |
| 11 | The next turn on that session | exit **3**, `budget exhausted`; no turn row is created |

The last two are the "stops within one turn" guarantee: every step is billed as it lands, so the
step that crosses the cap is charged and the turn ends before its next step; the next turn is then
refused before it starts.

## The pre-turn estimate

The composer quotes a turn before it is sent, so a large prompt against a nearly-spent cap is
visible before Enter rather than discovered in the bill. The quote is advisory; the cap is not.

- **What it prices.** The fixed request context (system prompt plus every tool schema, measured by
  `fixed_context_chars` so a prompt or schema change flows in) plus the typed prompt, at four
  characters per token. Output is unknown before the answer exists, so it assumes half the input,
  floored at 256 and capped at 2,048 tokens. `agent/pricing.rs` prices those tokens with the same
  table the bill uses when a provider returns no cost.
- **Where it comes from.** `turn_estimate` is session-scoped, not agent-scoped: the very first turn
  has no agent yet, and that is exactly when the quote is useful. It reads the session's
  `spend_micros` and `budget_cents` and writes nothing — no turn row, no charge.
- **What the user sees.** `≈ $0.005211 first step · $4.968600 left of $5.00`, debounced 250 ms after
  typing stops. When the estimate is more than remains, the line turns amber and says which of
  three things will happen: the step is over the cap but the turn can start (`the cap stops the turn
  after the step that crosses`), the remainder is below the one-cent reserve (`the turn will be
  refused before it starts`), or the session is already over the cap. Sending is never blocked by
  the quote; `reserve` and `account` still decide.
- **What it is not.** A turn may make several model calls, so this is a first-step estimate, not a
  forecast of the whole turn. The provider's usage replaces it as each step lands, and the transcript
  keeps the real figure.

## Why the kill is "after the journal"

A real `SIGKILL` at an arbitrary moment produces a nondeterministic mix of states. The failure this
item cares about is the one the write-ahead journal exists for: the patch row is committed, fsync'd,
and the rename has **not** happened. `--crash-after-journal` returns without closing the turn or
writing a checkpoint, which leaves exactly that state; the next section launches a genuinely new
process to reconcile it. `crates/rigel-core/tests/native.rs` covers the same path plus a real
panic-free process boundary.

What this does not prove: a real provider bill for the killed turn. Billing is per step, so the
two steps that returned usage **are** charged ($0.0013) while the step that was in flight when the
process died is not — the same is true of a laptop losing power. The next `resume` reconciles
recorded spend, not invisible spend; that is the honest limit of post-hoc accounting and is why the
cap can stop a turn between steps but never in the middle of a stream.

## Subagents

`spawn_agents` is part of the same loop: one step asks for children, each child runs its own turn on
an allowlisted cheap model, and only its final assistant message goes back to the parent as tool
output. The allowlist is eight models priced at $5/M output or less — GPT-5 nano, GPT-5.4 nano,
Gemini 2.5 Flash-Lite, DeepSeek V4.1 Flash, Qwen3 Coder 30B, Claude Haiku 5.5, Gemini 3 Flash and
GPT-5.4 mini — read from OpenRouter's live model list on 21 Oct 2026. The parent turn itself may use
the local OmniRoute router (the default provider) or OpenRouter (`--provider openrouter`).
Verified end to end with the
real binary on a throwaway crate, with the fixture naming a 5.4 nano reader and a DeepSeek reader:

```
rigel agent run --project "$TMP" --prompt "summarise the repo" --script scripts/fixtures/p4-subagents.json

agent: f8997770 · completed · 2 steps · 1 tool call · $0.000900
rigel agent list
f8997770  native  native         $0.0009  idle
0bed194f  native  readme-reader  $0.0001  idle
da8ce69b  native  lib-reader     $0.0001  idle
session_spend_micros: 1100
```

The parent's $0.0009 covers only its own two steps; the session pays $0.0011 including both
children. `crates/rigel-core/tests/native.rs` asserts the same split, that child turns carry
`parent_turn_id` and stay out of the top-level transcript, that a child is refused `edit_file` even
when it calls one, that a parent naming `openai/gpt-5.4-pro` gets `MODEL_NOT_ALLOWED` and no agent
row, and that `budget::reconcile` still balances. A unit test also fails if an allowlisted model
has no price row or would cost more than $5/M output.

Two tests cover the concurrency itself. `sibling_subagents_overlap_their_model_calls` uses a model
that records how many child calls are in flight; both children must be inside it at once (peak 2),
and the answers still come back in the order the parent asked for them.
`concurrent_usage_is_counted_once_per_charge` fires 20 charges across four agents at once and then
asserts the session total and `reconcile`. `stopping_a_parent_stops_the_children_it_spawned` cancels
the parent's token mid-fan-out and asserts both children close as `cancelled`: a child's turn token
is a child of its parent's, so a stop or budget kill cascades. That test also covers a stop landing
while a provider call is in flight — the step is still charged, and the turn closes `cancelled`
rather than `completed`. What this does not prove: a real provider bill for the cheap models.
